# pictures.js Docs

pictures.js is for making 2D and 3D graphics and games in plain JavaScript, and for enjoying it: you write a short `.js` file, with no HTML, and it draws in a web browser. It is for any age and any level, a first program or a thousandth, and is designed to bring the joy back into programming. Plain drawing functions get you started, with the web's 2D canvas for everything else in 2D, and three.js for 3D.

It is the JavaScript sibling of [Pyctures](https://www.circuitry.dev/pyctures) ([on GitHub](https://github.com/johnwylie70/pyctures)), which does the same from Python. A program has the same shape in either language, so what you learn in one carries over to the other.

Start here: [Getting started](getting-started.md).

pictures.js is designed for projects made in [Circuitry Studio](https://www.circuitry.dev), and runs anywhere a browser does. Its home page is [circuitry.dev/pictures](https://www.circuitry.dev/pictures).
